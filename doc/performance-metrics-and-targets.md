# Метрики и целевые значения

## Базовые страницы для контроля
- Главная: `/`
- Услуги: `/services`
- Проекты: `/projects`
- Портфолио: `/portfolio`

## Что измеряем
- PageSpeed Insights (mobile, desktop)
- Lighthouse (lab)
- Core Web Vitals (field, если доступно)

## Целевые показатели (mobile, ориентир)
- LCP: <= 2.5s
- INP: <= 200ms
- CLS: <= 0.1
- TTFB: <= 800ms
- Performance score: 80+ (стабильно)

## Формат фиксации результатов
Для каждого релиза оптимизации:
1. Дата и commit/release ID.
2. Список внесенных изменений.
3. Значения до/после по 4 ключевым страницам.
4. Вывод: что улучшилось, что осталось узким местом.

## Правила принятия изменений
- Не принимать изменения, если есть регресс по UX или функционалу.
- Не принимать изменения, если вырос CLS или появились JS-ошибки.
- Не принимать изменения, если ускорение получено за счет ломки SEO-критичных блоков.
